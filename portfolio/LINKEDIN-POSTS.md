## SOC Authentication Triage

I built SOC Authentication Triage, a small portfolio project exploring soc analyst workflows.

Group failed authentications by source and flag successful logins after repeated failures.

The demo includes synthetic data, editable JSON inputs, transparent decision rules and result exports. It runs locally in the browser. I built it with AI assistance and documented the assumptions and limitations so the implementation can be reviewed.

This is a learning project, not a production deployment or vendor-certified tool.
